## 三、已知冲突

### 一回合能打几张卷轴 —— 代码注释写反了

`scrolls/diceBoost.ts` 和 `equipment/accessories.ts` 里有两处注释写着「8.5——每方每回合最多一张卷轴」。

**这是错的。** GameRule §8.5 和 §27.3 都写的是「每方可以使用任意张卷轴，没有数量上限，平衡由单卡限制承担」，引擎的 `submitScrollChoice` 收的也是 `instanceIds: string[]`。

牵连到一个设计问题：命运王冠、王座破坏者、裂纹骰面、拾荒者背袋这一组「每场战斗一次的主动技」，注释里说它们的代价是「用它的那一轮就打不了 D20 或巨龙打击」的机会成本。**按实际规则，这个机会成本不存在**——同一轮可以既打王冠又打 D20。这四张卡当前只有「一场一张」这一层限制。

改不改是平衡决策，不是 bug 修复，动之前先确认。

## 四、写文档时的分工

新增或修订规则说明时，按这个放，不要重复：

- **怎么加一张卡、钩子有哪些时机、暗格与临时牌的约定** → `docs/content-extension.md`
- **牌面措辞与关键字** → 本 skill 的 `references/keywords.md`
- **原型对企划的有意偏离** → `README.md#当前原型规则`
- **一个特性为什么这么设计** → `docs/superpowers/specs/` 新开一份
- **企划层面的规则本身变了** → `docs/GameRule.md`，并同步 §26 / §27
