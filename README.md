# 骰境登峰

根据 [`docs/GameRule.md`](docs/GameRule.md) 实现的浏览器双人垂直切片。

## 运行

本地 2–4 人同屏热座只需要前端：

```powershell
npm.cmd install
npm.cmd run dev
```

联机对战还需要另开一个终端跑房间服务器：

```powershell
npm.cmd run dev:server
```

在菜单选「联机对战」，房主选择 2–4 人房间上限并获得 5 位房间码；至少两人入座且全员在线后，房主可以开始游戏。
本机自测可以打开多个浏览器标签页。

生产构建后 `npm start` 会同时提供静态页面和 WebSocket 服务：

```powershell
npm.cmd run build
npm.cmd start
npm.cmd test
```

## 当前已实现

- 全员投骰决定固定行动顺序、2–4 人轮流移动和三地区 108 格随机棋盘
- 每个地区独立限制战斗、事件、宝箱、赐福与泉水的最小/最大数量
- 三行棋盘支持拖动、滚轮缩放、总览与当前玩家定位
- 战斗、事件、宝箱、赐福、泉水和最终 Boss 格
- 先攻骰、攻防骰、0 点完全防御和战败退回休整点
- 力量/护盾/D20/巨龙打击/铁壁令/满载骰池，以及 N/R/SR/PR 稀有度卡池
- 装备分类槽位、槽满替换，以及攻击/防御/移动骰面的装备修正
- 七种可抽取永久赐福：数值强化、骰点保底、移动、额外奖励与 PvP 免罚
- 同格相遇战、多人同格目标选择、战后生命回溯、赐福自动夺取、资源或生命惩罚
- Boss 胜利、游戏结算和重新开局
- 带 seed 的确定性随机源和纯 TypeScript 规则引擎

## 联机

- 服务器权威：客户端只发 action，服务器跑引擎并把状态推回来
- 每位玩家收到的是**按自己座位裁剪过的视图**，不是同一份状态
- 卷轴为暗牌：对手手牌只显示张数与牌背；本回合待结算的卷轴选择也只透出「已提交」
- 身份用 `playerToken` 而非连接标识，断线后凭同一 token 回到原座位，对局不中断
- 掉线席位有 30 秒重连宽限；超时后自动跳过待操作阶段，PvP 中按战败后退处理
- 房间状态只在内存里，服务重启即清空；全员掉线超过 10 分钟的房间会被回收

## 当前原型规则

- 本地热座同样按暗牌处理：屏幕只显示当前该操作者的手牌，需要传递设备。
- 宝箱和事件可以重复触发。
- 装备槽限制为武器 1、防具 1、鞋具 1、饰品 2；槽满时替换或放弃。
- PvE 战败后恢复一半生命，并退至最近的前置休整点。
- Boss 战败时采用相同规则，Boss 再次挑战时恢复全部生命。

这些规则集中在 `src/game`，后续调整不会依赖界面组件。
新增卡牌与特殊效果的约定见 [`docs/content-extension.md`](docs/content-extension.md)。
