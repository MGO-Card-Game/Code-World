# 骰境登峰

根据 `GameRule.md` 实现的浏览器本地双人垂直切片。

## 运行

```powershell
npm.cmd install
npm.cmd run dev
```

打开终端显示的本地地址即可开始游戏。生产构建和测试：

```powershell
npm.cmd run build
npm.cmd test
```

## 当前已实现

- 投骰决定先手、双人轮流移动和固定 18 格蛇形棋盘
- 战斗、事件、宝箱、泉水和最终 Boss 格
- 先攻骰、攻防骰、0 点完全防御和战败退回休整点
- 力量/护盾卷轴，以及铁剑、木盾、生命护符
- 同格相遇战、战后生命回溯、资源或生命惩罚
- Boss 胜利、游戏结算和重新开局
- 带 seed 的确定性随机源和纯 TypeScript 规则引擎

## 当前原型规则

- 卷轴信息公开，适合同屏热座试玩。
- 宝箱和事件可以重复触发。
- 同名装备通过普通奖励最多获得两件。
- PvE 战败后恢复一半生命，并退至最近的前置休整点。
- Boss 战败时采用相同规则，Boss 再次挑战时恢复全部生命。

这些规则集中在 `src/game`，后续调整不会依赖界面组件。
